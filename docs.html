Everything you need to understand, extend, and deploy DataFlow Studio v14.0.

🏗️ Architecture

DataFlow v14.0 is a 100% client-side web application. No backend server, no database, no AI API calls. All processing happens in your browser using JavaScript.

🔐 Security Architecture

DataFlow v14.0 includes multi-layer security to prevent unauthorised access and tampering:

  • Content Security Policy (CSP) — restricts script sources to known CDN
  • Security headers — X-Frame-Options, X-Content-Type-Options, Referrer-Policy
  • License tier gating — premium modules require explicit upgrade
  • Server-side verification (planned) — subscription tokens validated by HMG Academy server
  • Integrity check — verifies required libraries are loaded
  • Module sanitization — invalid module IDs rejected
  • Rate limiting — prevents brute-force operations

All access tiers are ultimately managed server-side by HMG Academy via subscription tokens delivered to verified paying customers. The browser-side checks are deterrents only.

🔐 Security & Privacy

  • All processing happens in your browser. No data leaves your device.
  • No telemetry. No analytics by default.
  • No cookies. Only browser-native localStorage for preferences.
  • Content Security Policy (CSP) prevents XSS attacks
  • Security headers on all deployment platforms
  • License tier gating via signed tokens
  • Open source and auditable
