🚀 Deployment Guide

DataFlow Studio v14.0 is a 100% static site. Deploy to Vercel, Netlify, or Cloudflare Pages in minutes — all on free tiers. No build step, no runtime, no credit card required.

✅
No build step required! Pure static site. No Node.js, no Python, no runtime. Just upload files.

📋 Prerequisites

  • The dswf v3/ folder contents
  • GitHub account (recommended for auto-deploys)
  • Account on one of: Vercel, Netlify, or Cloudflare Pages (all free)

🚀 Option 1: Deploy to Vercel (Recommended)

Method A: Via Dashboard (Easiest — 30 seconds)

  1. Go to vercel.com/new
  2. Drag the dswf v3/ folder onto the upload area OR click "Import Git Repository"
  3. Configure:
    • Framework Preset: Other
    • Build Command: (leave empty)
    • Output Directory: . (root)
    • Install Command: (leave empty)
  4. Click Deploy
  5. Wait 30 seconds
  6. ✅ Site live at https://your-project.vercel.app

Method B: Via Vercel CLI

cd "dswf v3"
npx vercel --prod

Method C: GitHub Auto-Deploy

cd "dswf v3"
git init
git add .
git commit -m "DataFlow Studio v14.0 — HMG Academy Edition"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
# Connect repo on Vercel → auto-deploys on every push

The included vercel.json configures:

  • Clean URLs (e.g. /features instead of /features.html)
  • Security headers (X-Frame-Options, X-Content-Type-Options, CSP)
  • Cache headers (1 year for assets, no cache for HTML)
  • URL rewrites (e.g. /dashboard → /app.html)

🚀 Option 2: Deploy to Netlify

Method A: Via Dashboard

  1. Go to app.netlify.com/start
  2. Drag dswf v3/ folder
  3. Configure:
    • Build command: (empty)
    • Publish directory: . (root)
  4. Click Deploy site

Method B: Via Netlify CLI

cd "dswf v3"
npx netlify-cli deploy --prod --dir=.

The included netlify.toml is auto-detected and applied.

🚀 Option 3: Deploy to Cloudflare Pages

Best global CDN performance + unlimited bandwidth on free tier.

Method A: Via Dashboard

  1. Cloudflare → Workers & Pages → Create application → Pages
  2. Connect to Git (or drag folder via "Upload assets")
  3. Configure:
    • Build command: (empty)
    • Build output directory: . (root)
  4. Save and Deploy

Method B: Via Wrangler

cd "dswf v3"
npx wrangler pages deploy . --project-name=dataflow

The _redirects and _headers files are auto-applied.

🌐 Local Testing

Test before deploying:

cd "dswf v3"
python3 -m http.server 8000
# OR
npx serve .
# OR
php -S localhost:8000

Open http://localhost:8000/ in your browser.

🔒 Security Headers (Auto-Configured)

  • X-Content-Type-Options: nosniff
  • X-Frame-Options: SAMEORIGIN
  • Referrer-Policy: strict-origin-when-cross-origin
  • Permissions-Policy (geolocation, mic, camera disabled)
  • Content-Security-Policy (restricts script sources)
  • Strict-Transport-Security (Netlify)

🔧 Post-Deployment

  1. Update sitemap.xml with your actual domain
  2. Update robots.txt sitemap URL
  3. Submit sitemap to Google Search Console
  4. Verify PWA installation (Chrome DevTools → Application → Manifest)
  5. Run Lighthouse audit (aim for 90+ scores)

🐛 Troubleshooting

Charts not rendering

Open DevTools → Network tab → check for failed CDN requests to cdn.jsdelivr.net.

SQL Console not working

sql.js requires WebAssembly (all modern browsers support it).

Premium module shows lock

That's intentional. See pricing or contact HMG Academy to upgrade.

Service Worker not registering

Service workers require HTTPS (or localhost). All three platforms provide free HTTPS.

🔐 Production Security Checklist

  • ✅ Always use HTTPS
  • ✅ Verify CDN library versions are pinned
  • ✅ Don't expose subscription tokens in client code
  • ✅ Audit your custom modifications before deployment
  • ✅ Monitor usage via server-side logs (not in browser)
  • ✅ Keep license tier validation server-side for production
